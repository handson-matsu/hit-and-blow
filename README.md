# Hit and Blow（ヒット・アンド・ブロー）

中学3年生の数学の授業でも使える、1人用の数字推理ゲームです。HTML・CSS・JavaScriptだけで動作し、ゲーム本体は外部ライブラリ・API・フォント・通信を必要としません。アクセス記録だけに、既存教材と共通のGASを利用します。

## ゲームのルール

コンピュータが作った秘密の数字を推理します。使う数字は0〜9、重複なし。先頭の0も認めます。初期設定は3桁、回数制限はありません。

- **Hit**：数字と位置が両方一致した個数。
- **Blow**：数字は含まれるが位置が違う個数。

例：秘密の数字が `123`、予想が `132` なら **1 Hit・2 Blow** です。

## 操作方法

1. 2〜5桁のボタンで桁数を選びます。
2. 画面の数字ボタンかキーボードの数字キーで予想を入力します。
3. 入力がそろったら「判定する」を押します。画面の数字キーにフォーカスがないときはEnterキーでも判定できます。
4. 古い順に並ぶ履歴を手がかりに、次の予想を考えます。同じ予想を再び入力することもできます。

「1文字削除」またはBackspace / Deleteで末尾を削除、「全消去」またはEscapeで入力全体を消します。入力不足や数字の重複があると判定できません。重複する数字の入力時にはエラーを表示します。

「新しいゲーム」、または桁数変更でリセットします。判定済みまたは入力途中のゲームでは確認を表示します。正解後の「もう一度遊ぶ」は同じ桁数で開始します。

## 答えの一意性

| 桁数 | 最初の候補数 |
| --- | ---: |
| 2桁 | 90 |
| 3桁 | 720 |
| 4桁 | 5,040 |
| 5桁 | 30,240 |

ゲーム開始時に重複なしの全候補を一度生成し、各判定結果で現在の候補を絞り込みます。一意性判定の関数には秘密の数字を渡さず、予想とHit・Blowの結果のみを使います。各候補の数字集合をビットで保持して計算を軽くしています。

候補が初めて1つになると大きな「答えが1つに絞られました！」の通知を画面中央に表示します。通知には桁数分の「？」だけを表示し、入力操作を遮らず、正解するまで維持します。途中の候補数や正解の数字は表示しません。その後も自分で正解を入力するまで継続します。

全桁がHitになると正解です。正解の数字、判定した回数、一意に定まった判定回数を表示します。正解の判定で初めて一意になった場合は、その回数を記録します。

## ローカルで使う

`index.html` をブラウザで開くだけで動作します。ビルドやインストールは不要です。PC・iPad・スマートフォンに対応し、履歴は独立してスクロールできます。音は初期OFFです。「音 ON／OFF」で切り替えられます。効果音はWeb Audio APIで生成し、外部音声ファイルは使いません。一意性確定時は短い通知音、正解時は成功音と約2.8秒の紙吹雪を表示します。同時に起きた場合は正解の演出だけを行います。音はONにする操作で有効化し、端末の音量・消音設定にも依存します。音声非対応のブラウザでもゲームは継続できます。動きを減らす設定では紙吹雪を省略します。保存機能はありません。再読み込みするとゲームはリセットされます。

## 自動テスト

Node.js 18以降で、リポジトリ内から実行します。追加パッケージは不要です。

```sh
node --test script.test.cjs
```

2〜5桁の候補数、重複なし、先頭0、秘密の生成、入力検証、Hit・Blow、一意になる前後の候補を検証します。各段階の候補集合を、全履歴から独立した参照計算で求めた集合と比較します。全2桁の候補同士の8,100組についても判定を比較します。

## GitHub Pagesで公開する

1. このファイル群をGitHubの `hit-and-blow` リポジトリの公開用ブランチ（例：`main`）のルートにコミットしてpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選択します。
4. **Branch** に公開用ブランチ、フォルダに **/ (root)** を選び **Save** を押します。
5. デプロイ完了後、Pages画面に表示されるURLを開きます。通常は `https://ユーザー名.github.io/hit-and-blow/` です。

すべて相対パスなので、GitHub Pagesのサブディレクトリでも動作します。独自ドメインやGitHub Actionsの設定は不要です。

## ファイル

- `index.html`：日本語の画面・入力・履歴・ルール。
- `style.css`：レスポンシブな画面と控えめな通知アニメーション。動きを減らす設定にも対応。
- `script.js`：ゲーム進行と独立した判定・候補絞り込み処理。
- `script.test.cjs`：Node.js標準テストランナーによる自動テスト。

## アクセス記録

`access-counter.js` を独立して読み込み、ページを開くごとに1回だけ共通GASへアクセスを記録します。既存の `paper-copter-lab`・`chopsticks-game` と同じURL、`GET`、`mode: no-cors`、`cache: no-store`、`credentials: omit`、`keepalive: true` を使い、パラメータは `app=hit-and-blow` です。新しいGASは作成していません。

ゲームのリセット・桁数変更・再プレイでは送信しません。通信の失敗・未完了はゲームに影響せず、再送もしません。スクリプトが同じページで重複実行されても1回に抑えます。

アクセスの記録のみを行い、画面にはカウンターや通信状態を表示しません。既存方式の応答はopaqueのため、応答本文や累計数は読み取りません。

アクセス記録の自動テストも含める場合は `node --test script.test.cjs access-counter.test.cjs` を実行します。テストでは通信をモックし、実際のアクセス数を増やしません。
